# Sistema de Gestión para Ferretería - Documentación Técnica

Este repositorio contiene la documentación integral del sistema, abarcando desde el análisis de requerimientos hasta el diseño de arquitectura y pruebas.

## 📝 Descripción del Proyecto
El sistema está diseñado para optimizar el control de inventarios, ventas, cotizaciones y traspasos entre sucursales, permitiendo una gestión centralizada y eficiente para negocios de ferretería.

## 📂 Estructura de la Documentación
Para facilitar la revisión, la documentación se ha dividido en las siguientes áreas:

*   **[Requerimientos Generales](./docs/01-general/README.md):** Visión global y reglas de negocio.
*   **[Base de Datos](./docs/02-base-de-datos/README.md):** Modelo entidad-relación y especificaciones técnicas.
*   **[Frontend](./docs/03-frontend/README.md):** Diseño de interfaces y flujo de usuario.
*   **[Backend](./docs/04-backend/README.md):** Arquitectura de la API y lógica del servidor.
*   **[Testing y Reportes](./docs/05-testing/README.md):** Plan de pruebas y resultados.

## 🛠️ Stack Tecnológico Documentado
- **Backend:** Node.js / Express
- **Base de Datos:** MySQL
- **Frontend:** Flutter
- **Testing:** Postman
